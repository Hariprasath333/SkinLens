1

What SkinLens is

SkinLens looks at a photo of a skin spot (lesion) and suggests which of seven common lesion types it looks most like. It also shows where it looked (a heat-map), how sure it is (High / Medium / Low) and a short written explanation. It runs as a website on your own computer, which you can also open and install on a phone.

Doctor mode
Log in, keep patient records and scan history, read the full result (Grad-CAM, LIME, top 3), give feedback and download a PDF report.
Patient mode
No login. Take a photo, get a calm, plain-language result and advice. Nothing is stored.

How it works

The AI model

A hybrid network: EfficientNetV2-S (good at fine texture) + Swin Transformer V2 (good at overall shape) + a small network for age, sex and body site. Trained on HAM10000 (10,015 images).

The explanation

Grad-CAM colours the areas the model used most. LIME (doctor mode) is a second, independent check. The text describes border, colour and where the model looked.

Important: SkinLens is a research project for decision support. It is not a medical diagnosis and not a certified medical device.

Quick start

Already have Python 3.12 and the project folder? These five steps get you from zero to the start screen. Each step is explained in detail later in this guide.

1

Open PowerShell in the project folder

PowerShell
>cd C:\Users\<you>\Desktop\SkinClass\clinical_system
2

Create a virtual environment

PowerShell
>py -3.12 -m venv .venv
3

Install PyTorch (CPU version) and the requirements

PowerShell
>.\.venv\Scripts\python.exe -m pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu
>.\.venv\Scripts\python.exe -m pip install -r requirements.txt
4

Start the server

PowerShell
>.\.venv\Scripts\python.exe -m uvicorn webapp.main:app --host 0.0.0.0 --port 8080
5

Open the app and create the first account

Open http://127.0.0.1:8080 in a browser, choose I'm a doctor / clinic staff → Create an account. The first account becomes the Admin.

Timing on our test laptop: installation took about 10 minutes on home broadband; the first start (loading the model) took about 21 s; one analysis took about 8 s (LIME adds about 70 s in the background).

Requirements

What you need on the computer that runs SkinLens (the “server”). Phones only need a modern browser (Chrome on Android, Safari on iPhone).

Operating system

Windows 10 or 11, 64-bit.
Tested on Windows 11. macOS / Linux: see the side box in section 5 (not tested).

Python 3.12

64-bit, from python.org.
Tested with Python 3.12.6.

Disk space

about 2 GB free
virtual environment 1.25 GB + model file 0.41 GB + project.

Memory (RAM)

8 GB recommended
The running server used about 1.3 GB on our laptop.

Internet

only for the first installation
about 770 MB of downloads; fonts and charts also load from the internet.

GPU NOT needed

Everything runs on a normal CPU.
A GPU is only needed to train new models (Kaggle).

Short folder path: keep the project in a short path such as C:\Users\<you>\Desktop\SkinClass. In a very deep folder, installing PyTorch fails on Windows with [WinError 206] The filename or extension is too long (this happened in our test).

Installation (Windows)

1

Install Python 3.12

Download the Windows installer (64-bit) from python.org and run it. Check that it works:

PowerShell
>py -3.12 --version
Output
Python 3.12.6
Why “py” and not “python”? on many Windows PCs, typing python opens the Microsoft Store placeholder and prints “Python was not found” (it did on our laptop). The Python launcher py -3.12 always finds the real Python.
2

Get the project folder

Copy or unzip the SkinClass folder, e.g. to your Desktop. Then open PowerShell (Start menu → type PowerShell) and go to the app folder:

PowerShell
>cd C:\Users\<you>\Desktop\SkinClass\clinical_system
3

Create a virtual environment

A private place for SkinLens' packages (takes about 20 s):

PowerShell
>py -3.12 -m venv .venv

macOS / Linux

Not tested on this project. The steps are the same with these differences:

  • use python3.12 instead of py -3.12
  • use .venv/bin/python instead of .\.venv\Scripts\python.exe
  • use / instead of \ in paths
  • find the IP address with ipconfig getifaddr en0 (macOS) or hostname -I (Linux)

If something fails there, check the Troubleshooting section.

SkinLens – For research and decision-support only. Not a medical diagnosis.

Install PyTorch (CPU version)

The CPU version is smaller and needs no graphics card (about 285 s on our laptop):

PowerShell
>.\.venv\Scripts\python.exe -m pip install --upgrade pip
>.\.venv\Scripts\python.exe -m pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu

Install the other requirements

FastAPI, timm, OpenCV and the rest (about 301 s):

PowerShell
>.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Output
Successfully installed albucore-0.0.24 albumentations-2.0.8 ... (and the other packages)
6

Check that the model file is found

The model must be at SkinClass\backup\original_model\best_skinlens_hybrid.pt. This command loads it (takes about 25 s):

PowerShell
>.\.venv\Scripts\python.exe -c "from webapp.ml.predictor import get_predictor; print(get_predictor().display_name)"
Output
SkinLens hybrid (EfficientNetV2-S + Swin V2 + metadata) + prior correction (alpha=0.3)
Done! if you see the model name with “prior correction (alpha=0.3)”, the installation is complete. You do not need to “activate” the virtual environment: every command calls .\.venv\Scripts\python.exe directly.

Using the mobile app

You can use SkinLens on a phone in two ways: quickly over the same Wi-Fi (a web page), or as an installed app with its own icon (needs HTTPS – we use a free Cloudflare tunnel).

(a) Same Wi-Fi – the quick way

1

Start the server for the network

PowerShell
>.\.venv\Scripts\python.exe -m uvicorn webapp.main:app --host 0.0.0.0 --port 8080

It prints the phone address, e.g. http://192.168.31.11:8080.

2

Or find the IP address yourself

PowerShell
>ipconfig
Output
Wireless LAN adapter Wi-Fi:
   IPv4 Address. . . . . . . . . . . : 192.168.31.11

Use the IPv4 address of your Wi-Fi adapter: http://<laptop-IP>:8080.

Firewall: the first time, Windows asks if Python may use the network: tick Private networks → Allow.
3

Open it on the phone

Phone on the same Wi-Fi, type the address in Chrome or Safari. To get an icon: browser menu → Add to Home screen.

SkinLens – For research and decision-support only. Not a medical diagnosis.

(b) Install as an app – HTTPS with a free Cloudflare quick tunnel

Phones only offer Install (and the offline page) on secure https:// addresses. A Cloudflare quick tunnel gives your laptop a temporary https address – no account needed.

1

Install cloudflared (once)

PowerShell
>winget install --id Cloudflare.cloudflared
Then open a NEW PowerShell window. In the old window you get “cloudflared is not recognized”. Without a new window you can use the full path:
PowerShell
>& "C:\Program Files (x86)\cloudflared\cloudflared.exe" --version
Output
cloudflared version 2026.11.0 (built 2026-11-12T03:21 UTC)
2

Start the tunnel (server must be running)

PowerShell
>cloudflared tunnel --url http://localhost:8080
It prints (address changes every time)
INF Requesting new quick Tunnel on trycloudflare.com...
INF |  Your quick Tunnel has been created! Visit it at (it may take some time to be reachable):  |
INF |  https://furniture-passage-substances-highway.trycloudflare.com                            |
3

Install on the phone

Open the https://…trycloudflare.com address. Android (Chrome): tap Install SkinLens on the start screen (or menu → Install app). iPhone (Safari): Share → Add to Home Screen. SkinLens then opens full screen from its own icon.

The tunnel is public: anyone with the address can open the app while the tunnel runs. Create staff accounts first, then restart the server with $env:ALLOW_REGISTRATION="0"; $env:COOKIE_SECURE="1" before the uvicorn command, and stop the tunnel with Ctrl + C when you are done.

Taking a good photo

The model was trained on clear, close-up (dermoscopic) images. A good photo gives a more reliable result.

Good light

Daylight or a bright room. No flash glare or shadows.

In focus

Tap the screen on the spot to focus before you take the photo.

About 10 cm away

Close enough that the spot fills a good part of the picture.

Lesion in the centre

Keep hair, rulers and ink marks off the spot if you can.

Ask first: always get the person's consent before photographing their skin.

Troubleshooting

Common problems and fixes. tested means we saw the problem and checked the fix on our laptop; the others are marked “if this happens”.

ProblemFix
“Python was not found”
Typing python opens the Microsoft Store placeholder.
Use the launcher: py -3.12 … (as in this guide). tested
Install fails: [WinError 206] filename too long
The project is in a very deep folder.
Move SkinClass to a short path, e.g. the Desktop, and repeat the installation. tested
Port already in use
Error: [Errno 10048] error while attempting to bind on address ('0.0.0.0', 8080): only one usage of each socket address (protocol/network address/port) is normally permitted
Another server is still running. Close it (Ctrl + C), or find it with netstat -ano | findstr :8080, or use --port 8081. tested
Requirements install fails
Network or proxy problem, or a wrong Python version.
If this happens: check the internet connection, run the pip upgrade command again, and make sure py -3.12 --version shows 3.12.
Model file not found
The server log says the model could not be loaded.
If this happens: check that SkinClass\backup\original_model\best_skinlens_hybrid.pt and SkinClass\backend\model\architecture.py exist next to clinical_system, then run the model check command (section 5).
LIME is slow
LIME took about about 70 s on our CPU.
Normal – it runs in the background and the page shows it when ready. To make it faster, start the server with fewer samples: $env:LIME_SAMPLES="30" before the uvicorn command (if this happens).

Model and results

Model

Hybrid of EfficientNetV2-S + Swin Transformer V2-Base + a small network for age, sex and body site (108 million parameters, input 384 × 384). Prior correction (alpha = 0.3) adjusts the probabilities for how common each lesion type is.

Data

HAM10000: 10,015 dermoscopic images of 7,470 lesions, 7 classes. Lesion-grouped split: photos of the same lesion never appear in both training and test (test set: 2,014 images).

85.80%test accuracy
85.45% before prior correction
0.763macro-F1
78.8%melanoma recall
90.6%of High-confidence results were correct

Figures from clinical_system\paper_figures (Kaggle evaluation on the test set). Some curves also show other settings that were compared (e.g. test-time augmentation); the app uses prior correction with alpha = 0.3 and no augmentation.

Safety and privacy

  • Decision support only. SkinLens is a research project, not a certified medical device and not a diagnosis. A qualified clinician makes every decision; suspicious lesions need a dermatologist.
  • Patient mode stores nothing. No database entry, no saved photo; the upload's temporary file is deleted immediately.
  • Passwords are hashed (bcrypt), sessions are signed cookies, every form has a CSRF check; images are shown only to logged-in staff allowed to see that patient.
  • Get consent before photographing anyone, and follow your institution's rules for patient data.
Known limits: the model sometimes looks outside the lesion; it was trained mostly on light skin (limited data for darker skin tones); phone photos are not dermoscopy images; results on other clinics' images may be lower.
Public tunnel: the Cloudflare quick tunnel makes the app reachable from the internet while it runs – turn off registration, use secure cookies and stop it when done (section 8b).
